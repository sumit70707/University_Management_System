# 📌 Project Overview

The **University Management System (UMS)** is a desktop-based application designed to digitalize and automate the operations of universities, colleges, and educational institutions.

UMS integrates multiple modules such as **Student Information**, **Teacher Data**, **Examination**, **Fee Management**, **Subjects**, and more.

It provides a **user-friendly interface**, ensures **faster access**, removes **manual workload**, and supports **accurate reporting**.

---

# 🎯 Purpose of the Project

- Increase operational efficiency  
- Reduce duplicate data entries  
- Provide self-service system with minimal training  
- Enable automation of Academic, Administrative & Examination processes  
- Improve reporting accuracy  
- Maintain unified data and workflow  
- Provide monitoring & decision support system  

---

# 📍 Scope

This system manages various activities of a college, including:

- Student Registration  
- Teacher Record Management  
- Fee Management  
- Attendance  
- Exam Records  
- Marks Entry  
- Subject Assignment  
- User Login & Authentication  

The existing manual system had errors, delays, and heavy workload. UMS automates these operations efficiently.

# 🧩 Database Tables

1. **Account** – Stores login and signup details  
2. **Student** – Student personal & academic information  
3. **Teacher** – Teacher profile and academic details  
4. **Subject** – Subjects assigned to students  
5. **Marks** – Marks of students for each subject  
6. **Fee** – Fee payment records for each semester
